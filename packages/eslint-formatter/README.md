# @safety-web/eslint-formatter

[ESLint formatter](https://eslint.org/docs/latest/extend/custom-formatters) that
presents the results of @safety-web/eslint-plugin. This formatter only makes
sense when @safety-web/eslint-plugin is also installed.

## Installation

With Yarn:

```bash
yarn add -D @safety-web/eslint-formatter
```

or NPM:

```bash
npm install -D @safety-web/eslint-formatter
```
